# Daylight Weather

A lightweight, responsive weather app with city search, live conditions, and a five-day forecast. Built with plain HTML, CSS, and JavaScript—no server, build step, dependencies, or API key required.

## Run it

Open `index.html` in a modern web browser. An internet connection is needed for live weather and city search; if live weather is unavailable, the app displays sample weather.

## Features

- Tokyo weather shown by default, with search for other cities
- Current temperature, conditions, wind, humidity, and feels-like temperature
- Five-day forecast with daily highs, lows, and precipitation chances
- Celsius and Fahrenheit toggle
- Responsive layout and automatic light/dark theme
- Weather-appropriate accent colors

## Weather data

Live weather and geocoding are provided by [Open-Meteo](https://open-meteo.com/). No API key is needed.
